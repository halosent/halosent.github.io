# Live Orthodox, Discord Server Blueprint

A note on how to use this: Discord does not let outside tools create a server on your behalf, you have to build it inside Discord yourself. But you can set this up in about ten minutes by creating each category and channel below in order. Once it is built the way you like, you can turn it into a shareable Discord Server Template from Server Settings so you never have to do this again, or so others can clone the structure.

## Server icon and banner

Use the logo files in this folder:
- **Server icon**: `logo-icon-filled-512.png` (Server Settings → Overview → Server Icon)
- **Server banner** (if your boost level supports it): `logo-full-dark.png`, built for dark backgrounds

## Roles

Create these from top to bottom in Server Settings → Roles. Color hex codes match the site's gold and ivory palette.

| Role | Color hex | Purpose |
|---|---|---|
| Unified | `#A9812F` | You, the owner. Full permissions. |
| Moderator | `#5F4C30` | Trusted members who can manage messages and mute. |
| Contributor | `#D6B06A` | People who've written or submitted articles, or are known regulars. |
| Verified Debater | `#8A8074` | Opt-in role for people who agree to the debate channel rules. |
| Member | default grey | Everyone, on joining. |
| Bots | default | Assign automatically to any bots you add. |

## Categories and channels

### 📜 WELCOME
- `#welcome`, read-only, pinned server rules and a short explanation of what Live Orthodox is
- `#announcements`, read-only, new articles and site updates posted here
- `#introduce-yourself`, new members say hello

### ✝️ LIVE ORTHODOX
- `#general`, open chat, anything on-topic for Christianity and the site
- `#new-articles`, auto or manual post whenever a new essay goes up, link back to the site
- `#ask-unified`, direct questions for you specifically

### ⚖️ DEBATE HALL
- `#debate-rules`, read-only, pinned format expectations (see suggested rules below)
- `#contradictions-debate`, Genesis, genealogies, Judas' death, resurrection accounts, and similar objections
- `#metaphysics-debate`, problem of evil, free will, contingency, classical theism generally
- `#trinity-and-theology`, Trinity, essence and energies, Christology
- `#comparative-religion`, lower traffic channel for cross-tradition discussion, kept separate so it does not crowd out the main focus

### 📖 STUDY
- `#scripture-study`, passage by passage discussion, less adversarial than the debate hall
- `#church-fathers`, patristic quotes, recommended reading, translations
- `#resource-sharing`, books, papers, lecture links

### 🔊 VOICE
- `Debate Stage`, a Stage Channel for structured, moderated live debates
- `General Voice`, open hangout
- `Study Voice`, quiet reading or discussion room

### 🛠 STAFF (private, visible to Moderator and Unified only)
- `#mod-chat`
- `#reports`

## Suggested pinned rules for #debate-rules

Keep this short and pin it. A starting point:

1. Attack the argument, not the person.
2. Cite your source when you reference a verse, translation, or historical claim.
3. Steelman the other side before you respond to it.
4. No brigading other members' posts elsewhere on Discord.
5. Disagreement is welcome here. Hostility is not.

## Setting it up as a reusable template

Once the server is built:
1. Go to **Server Settings → Server Template**.
2. Click **Create Template**, give it a name like "Live Orthodox Base".
3. Discord will generate a link you can use to spin up fresh copies of this exact structure later, or share with others building a similar community.
